DevSweep looks for folders that a build tool or package manager recreates on its own, such as node_modules, .next and Rust target, and for package caches such as the npm and Cargo caches.

  • A folder only counts when its project file sits next to it, for example node_modules next to package.json.
  • Program Files, AppData, editor extensions, game libraries and .git are never scanned, so installed programs are not touched.
  • Folders used by a running dev server, build or program are locked and cannot be selected.
  • Everything is checked again right before it is deleted.
